# Zelland source grant

On 2026-07-19, the Choosh project owner and copyright holder of the Zelland
renderer/Android bridge explicitly authorized Choosh to use the Zelland source freely.
This records permission to copy, modify, build, distribute, and sublicense the exact
Zelland source committed as `8bf9cf55911588451804a39526f8ae869da021b6` as part of
Choosh.

This grant covers Zelland-owned code only. It does not alter the licences or source-offer
obligations of libghostty-vt, wgpu, glyphon, fonts, or any other dependency. Those remain
subject to the separate provenance and distribution gates.
